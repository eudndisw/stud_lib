# Інтеграційне тестування

**Мета:** Перевірити, що всі компоненти (інтерфейс, контролери, сервіси, репозиторії, БД, безпека) працюють разом і виконують вимоги.

## Підготовка
1. `docker compose up -d` (БД зі схемою та початковими даними).
2. Завантажити демонстраційні дані:
    * `docker cp docs\demo_data.sql student-library-db:/tmp/demo_data.sql`
    * `docker exec student-library-db psql -U postgres -d student_library -f /tmp/demo_data.sql`
3. Запустити застосунок і відкрити <http://localhost:8082>.
4. Акаунти: `admin@library.com` / `admin123`, `librarian@library.com` / `librarian123`, `student@library.com` / `student123`.
