# Студентська бібліотека

Веб-застосунок для автоматизації студентської бібліотеки: облік книжкового фонду, читачів, авторів і категорій, видача та повернення літератури з автоматичним контролем ліміту (не більше 5 книг на читача).

## Стек технологій
* **Backend:** Java 17, Spring Boot 3.2, Spring MVC, Spring Data JPA (Hibernate), Spring Security 6
* **Frontend:** Thymeleaf, Bootstrap 5, HTML5/CSS3
* **База даних:** PostgreSQL 15
* **Збірка:** Apache Maven 3.9
* **Тести:** JUnit 5, Mockito
* **Контейнеризація:** Docker (PostgreSQL та застосунок)

## Архітектура
Застосунок побудовано за шаблоном MVC зі структурою **Controller → Service → Repository**.

```text
stud_lib/
├── docs/                         # документація та БД
│   ├── db_schema.sql             # схема БД, індекси, початкові дані
│   ├── demo_data.sql             # демонстраційні дані (25 книг, автори, читачі)
│   └── integration_testing.md    # сценарії інтеграційного тестування
├── src/
│   ├── main/
│   │   ├── java/com/library/studentlibrary/
│   │   │   ├── config/           # SecurityConfig
│   │   │   ├── controller/       # Home, Book, User, Author, Category, IssuedBook, Profile
│   │   │   ├── dto/              # BookForm, UserForm
│   │   │   ├── entity/           # User, Role, Book, Author, Category, IssuedBook
│   │   │   ├── exception/        # BusinessException
│   │   │   ├── repository/       # інтерфейси Spring Data JPA
│   │   │   └── service/          # інтерфейси сервісів, PageUtil
│   │   │       └── impl/         # реалізації сервісів, CustomUserDetailsService
│   │   └── resources/
│   │       ├── static/css/       # style.css
│   │       ├── templates/        # Thymeleaf-шаблони
│   │       │   ├── fragments/    # layout.html (head, навігація, flash, пагінація)
│   │       │   └── error/        # сторінка 403
│   │       └── application.properties
│   └── test/                     # unit-тести сервісів
├── tools/
│   └── load_test.py              # навантажувальний тест (50 користувачів)
├── .gitignore
├── Dockerfile
├── docker-compose.yml            # PostgreSQL та (за профілем app) застосунок
├── pom.xml
└── README.md
```

## Запуск програми

### Варіант 1. Розробка (база в Docker, застосунок з IDE)
1. Встановити JDK 17+, Maven 3.9 і Docker.
2. Підняти базу даних (схема та початкові дані з `docs/db_schema.sql` застосовуються автоматично):
   ```bash
   docker compose up -d
   ```
3. Запустити застосунок з IntelliJ IDEA (клас `StudentLibraryApplication`) або командою:
   ```bash
   mvn spring-boot:run
   ```
4. Відкрити <http://localhost:8082>.

## Виконання функціональних вимог

* **Облік читачів:** Додавання, редагування, видалення читачів; перегляд зі сортуванням за іменем, прізвищем та групою (`/users`, `UserController`, `UserServiceImpl`).
* **Облік літератури:** Повний цикл обліку книг, авторів та категорій (`/books`, `/authors`, `/categories`).
* **Швидкий пошук:** Пошук за параметром `q` у `/books` і `/users` (слова шукаються в назві/авторі/категорії книги, а для читачів — в імені, прізвищі, групі, email).
* **Сортування:** Сортування літератури за назвою, автором або роком (`sort=title|author|year`, `dir=asc|desc`).
* **Перевірка стану:** Відображення доступності книги («є в наявності / у конкретного читача») у колонках «Стан» та «У читачів».
* **Контроль видачі:** Автоматичний контроль ліміту (до 5 книг на руках) та оформлення повернення (`IssuedBookServiceImpl.issueBook / returnBook`).
* **Розмежування доступу:** Авторизація та розмежування ролей за допомогою `SecurityConfig`.
* **Перевірка унікальності:** Валідація унікальності email читача, автора (ім’я + прізвище) та категорії; унікальний індекс активної видачі на рівні БД.
* **Зворотний зв’язок:** Відображення flash-повідомлень про успіх або помилки операцій у `layout.html`.

## Виконання нефункціональних вимог

* **Обмеження видачі (Пагінація):** Каталог видається порціями не більше 50 записів за запит (`PageUtil.MAX_PAGE_SIZE = 50`; перевірено тестом `PageUtilTest`).
* **Швидкодія каталогу:** Час відгуку ≤ 800 мс при 50 одночасних користувачах (індекси БД `pg_trgm`, `@EntityGraph` проти N+1, пул з’єднань 20; перевіряється скриптом `python tools/load_test.py`).
* **Безпека паролів:** Збереження паролів лише у вигляді BCrypt-хешів (`BCryptPasswordEncoder`, поле `password_hash`).
* **Таймаут сесії:** Автоматичне завершення сесії користувача через 30 хвилин (`server.servlet.session.timeout=30m`).
* **Сумісність з браузерами:** Використання стандарту Bootstrap 5 без специфічного коду для коректного відображення в усіх сучасних браузерах.
* **Вимоги до ресурсів:** Апаратні обмеження сервера 1–2 vCPU та 1,5–2 ГБ ОЗП (опція `-Xmx512m` у `Dockerfile`, ліміт контейнера 1 ГБ).
* **Цілісність даних:** Блокування рядка книги під час видачі/повернення, обмеження `CHECK` на кількість примірників у БД.

## Тестування

Виконання автоматизованих модульних тестів:
```bash
mvn test
```
Модульні тести покривають бізнес-логіку видачі й повернення книг, керування користувачами, книгами, авторами, категоріями, а також пагінацію й пошук. Сценарії ручного інтеграційного тестування знаходяться в `docs/integration_testing.md`.

Запуск навантажувального тестування (за умови запущеного застосунку та завантаженого `docs/demo_data.sql`):
```bash
python tools/load_test.py
```

## Управління залежностями
Усі версії бібліотек (Spring Boot, Hibernate, Thymeleaf, Jackson, Mockito, драйвер PostgreSQL) керуються через `spring-boot-starter-parent` у `pom.xml`, що забезпечує їх повну сумісність.
